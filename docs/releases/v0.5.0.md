Local-first AI job search workbench, job application tracker, and MCP server in Rust.

### Opening the unsigned macOS Desktop App

Job Harness is free, open-source software distributed without an Apple Developer ID signature. On first launch on macOS:

1. Unzip `Job-Harness-v0.5.0-aarch64-apple-darwin.app.zip` and drag **Job Harness.app** into `/Applications`.
2. Right-click **Job Harness.app** → **Open** (or run once in Terminal: `xattr -d com.apple.quarantine "/Applications/Job Harness.app"`).
3. On first launch, click **Try with sample data** to explore a pre-filled 10-role workspace with CVs, interview briefs, Kanban, and Sankey immediately — no terminal or personal data required.

### CLI Quick Install (1 line)

```sh
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/machineyearningengineer/job-harness/main/scripts/get.sh | sh
```

Or paste into Claude Code, Codex, Hermes, Cursor, or OpenCode:
`Read https://raw.githubusercontent.com/machineyearningengineer/job-harness/main/docs/AGENT-SETUP.md and set up Job Harness for me at ~/Career/workspace.`

Run a ledger on an always-on Linux server and use it from the desktop app over SSH, with nothing listening on a network port and chat that survives a dropped connection.

## Highlights

- **Unix socket only, no token.** `jh serve` listens on a Unix socket; its file permissions are the access control. The TCP listener and bearer tokens are removed. **Breaking:** re-run `jh service install` on the server, and point remote-mode agents at the socket with `jh configure --remote unix:PATH`.
- **The app keeps its own SSH connection.** One supervised OpenSSH ControlMaster per window forwards the server's sockets. If the link drops, the board stays as last seen, read-only, with a Reconnecting banner, then Offline and Retry; nothing is queued.
- **Chat that survives disconnects.** `jh agent-host` keeps ACP agents (Hermes, Gemini, Claude Code or Codex adapters, your own) running on the server. A reply keeps streaming there while you are offline and the app picks it up where it left off. Sessions, images, fast mode, models and permission prompts follow what the agent supports.
