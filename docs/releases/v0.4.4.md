# Job Harness v0.4.4

Local-first AI job search workbench, job application tracker, and MCP server in Rust.

| Platform | Status | Download |

All release archives are verified against `SHA256SUMS`.

### Opening the unsigned macOS Desktop App

Job Harness is free, open-source software distributed without an Apple Developer ID signature. On first launch on macOS:

1. Unzip `Job-Harness-v0.4.4-aarch64-apple-darwin.app.zip` and drag **Job Harness.app** into `/Applications`.
2. Right-click **Job Harness.app** → **Open** (or run once in Terminal: `xattr -d com.apple.quarantine "/Applications/Job Harness.app"`).
3. On first launch, click **Try with sample data** to explore a pre-filled 10-role workspace with CVs, interview briefs, Kanban, and Sankey immediately — no terminal or personal data required.

A patch release that hardens remote mode.

## Highlights

- **`jh serve` takes requests up to 8 MiB**, so `save_artifact` accepts its documented 5 MB. A request the server rejects now returns a non-retryable `invalid_arguments` instead of `remote_unavailable`.
- **Desktop token and settings:** `--token-file` wins over `JOB_HARNESS_SERVE_TOKEN`, empty values are ignored, and an unreadable token file stops the app with the reason. Without arguments the app opens the remote saved by `jh configure --remote`, and it honours `XDG_CONFIG_HOME`.
