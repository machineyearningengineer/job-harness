# Job Harness v0.4.0

Local-first AI job search workbench, job application tracker, and MCP server in Rust.

## Downloads & Supported Platforms

| Platform | Status | Download |
|---|---|---|
| **macOS (Apple Silicon `arm64`)** | Primary (verified) | `Job-Harness-v0.4.0-aarch64-apple-darwin.app.zip` (Desktop app) + `job-harness-v0.4.0-aarch64-apple-darwin.tar.gz` (CLI) |
| **macOS (Intel `x86_64`)** | Preview | `Job-Harness-v0.4.0-x86_64-apple-darwin.app.zip` + CLI archive |
| **Linux (`x86_64` / `aarch64`)** | Preview | CLI & desktop binary archives (`.tar.gz`) |
| **Windows (`x86_64`)** | Preview | CLI & desktop binary archives (`.zip`) |

All release archives are verified against `SHA256SUMS`.

### Opening the unsigned macOS Desktop App

Job Harness is free, open-source software distributed without an Apple Developer ID signature. On first launch on macOS:

1. Unzip `Job-Harness-v0.4.0-aarch64-apple-darwin.app.zip` and drag **Job Harness.app** into `/Applications`.
2. Right-click **Job Harness.app** → **Open** (or run once in Terminal: `xattr -cr "/Applications/Job Harness.app"`).
3. On first launch, click **Try with sample data** to explore a pre-filled 10-role workspace with CVs, interview briefs, Kanban, and Sankey immediately — no terminal or personal data required.

### CLI Quick Install (1 line)

```sh
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/machineyearningengineer/job-harness/main/scripts/get.sh | sh
```

Or paste into Claude Code, Codex, Hermes, Cursor, or OpenCode:
`Read https://raw.githubusercontent.com/machineyearningengineer/job-harness/main/docs/AGENT-SETUP.md and set up Job Harness for me at ~/Career/workspace.`

The first published release since v0.2.0 (the v0.3.0 tag was never released), and the first with the native GPUI desktop app and `jh serve`.

## Highlights

- **Run on a Linux server:** `jh service install --port N` sets up systemd user units for `jh serve` on loopback and a 15-minute `jh sync` (SQLite checkpoint, commit if changed, push); `jh open --ssh user@host` tunnels to it and opens the desktop app. See [docs/LINUX-SERVER.md](https://github.com/machineyearningengineer/job-harness/blob/main/docs/LINUX-SERVER.md).
- **Ledger/binary version check:** a ledger in the old `state.json` format, or one written by a newer binary, now fails with the version it needs and how to install it. Update by re-running `get.sh`.

- **Zero-CLI first run:** Built-in **Try with sample data**, **Create my workspace**, and **Open existing folder** launchpad right inside `Job Harness.app`.
- **Native GPUI desktop workbench:** Instant Kanban board, interactive **Current / All-time** Sankey funnel, 2-layer company + round interview briefs, CV track & cover letter toggles, Driver.js-style moving spotlight tour, and native macOS notifications (`UNUserNotificationCenter`).
- **Any-agent chat & model discovery:** Auto-detects Hermes, Claude Code, Codex, Pi, OpenCode, Antigravity, and custom agents registered in `~/.config/job-harness/runtimes.json` with live model lists.
- **Native SQLite WAL (`harness.sqlite`) & hard safety rails:** Immutable SHA-256 submission packets, daily caps, live Sent-mail verification, canonical `outcome` / `company_id` tracking, and 1-use self-destructing ephemeral secret handoff (`jh secret`).
