Local-first AI job search workbench, job application tracker, and MCP server in Rust.

### Opening the unsigned macOS Desktop App

Job Harness is free, open-source software distributed without an Apple Developer ID signature. On first launch on macOS:

1. Unzip `Job-Harness-v0.4.5-aarch64-apple-darwin.app.zip` and drag **Job Harness.app** into `/Applications`.
2. Right-click **Job Harness.app** → **Open** (or run once in Terminal: `xattr -d com.apple.quarantine "/Applications/Job Harness.app"`).
3. On first launch, click **Try with sample data** to explore a pre-filled 10-role workspace with CVs, interview briefs, Kanban, and Sankey immediately — no terminal or personal data required.

A patch release so the desktop app's chat works against a server.

## Highlights

- **Chat runs on the server.** `jh open --ssh user@server --hermes-profile NAME` makes the desktop chat run that server's Hermes over SSH, where the agent and its profile live, instead of a Hermes on your computer.
- **No assumed Hermes profile.** Without `JOB_HARNESS_HERMES_PROFILE`, Hermes uses its own active profile. Before, chat failed with "Profile ... does not exist".
- **`jh open` starts the app binary directly**, so `JOB_HARNESS_SERVE_TOKEN` reaches it and two servers can be open side by side.
