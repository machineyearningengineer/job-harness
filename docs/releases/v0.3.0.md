# Job Harness v0.3.0

Local career state, safety guardrails, and daily workflows for any AI agent.

## Install (1 line)

- **macOS / Linux:**
  ```sh
  curl -fsSL https://raw.githubusercontent.com/machineyearningengineer/job-harness/main/scripts/get.sh | sh
  ```
- **Windows (PowerShell):**
  ```powershell
  irm https://raw.githubusercontent.com/machineyearningengineer/job-harness/main/scripts/get.ps1 | iex
  ```
- **Cargo:** `cargo install --git https://github.com/machineyearningengineer/job-harness job-harness`
- **Or paste into your AI agent:**
  `Read https://raw.githubusercontent.com/machineyearningengineer/job-harness/main/docs/AGENT-SETUP.md and set up Job Harness for me at ~/Career/workspace.`

All release archives are verified against `SHA256SUMS`.

## Highlights

- **Native SQLite WAL (`harness.sqlite`):** Replaces `state.json` with normalized tables, indexes, and concurrent WAL reads/writes.
- **Deterministic derived primitives:**
  - `bootstrap.data.daily_budget` reports exact total and per-channel daily submission caps (`portal`, `direct_email`, `recruiter_outreach`).
  - `review_queue` computes `urgency` (`urgent_now` / `upcoming` / `background`), `needs_attention_now`, `next_upcoming_interview`, `quiet_applied_count`, and CV `track_fit` gaps from `clock` + `time_and_reminders` (default 90-minute interview prep lead time).
- **Faster local reads:** Cached pipeline regexes and schemas, eliminated full-state read clones, and indexed read-only SQLite event filtering.
- **Leaner core:** Removed unused ACP transport/dependencies and fixed `intake::list` on workspaces containing plain Markdown files in `context/intake/`.
- **Simple agent onboarding:** Added `docs/AGENT-SETUP.md` and explicit 5-switch fail-closed defaults in `config/career-ledger.json`.

## Upgrade note

v0.3.0 uses `applications/operations/harness.sqlite` natively (no permanent `state.json` shim). New workspaces initialize SQLite WAL automatically via `jh setup`.
