# Job Harness v0.4.0

Local-first AI job search workbench, application tracker and MCP server in Rust.

This is the first published release since v0.2.0. The v0.3.0 tag was never released, so these notes cover everything since v0.2.0.

## Install or update

```sh
# macOS / Linux: checksum-verified install into ~/.local/bin (re-run to update)
curl -fsSL https://raw.githubusercontent.com/machineyearningengineer/job-harness/main/scripts/get.sh | sh

# or Homebrew
brew install machineyearningengineer/tap/job-harness          # jh CLI
brew install --cask machineyearningengineer/tap/job-harness-desktop   # macOS desktop app
```

Windows: `irm https://raw.githubusercontent.com/machineyearningengineer/job-harness/main/scripts/get.ps1 | iex`

**Upgrading from 0.2.x:** this release stores ledger state in `applications/operations/harness.sqlite`, not `state.json`. A 0.2.x ledger is refused with a message that names the version it needs; it is never converted or overwritten. Keep using 0.2.0 for that ledger (`JOB_HARNESS_VERSION=v0.2.0` with `get.sh`), or start a new ledger with `jh setup`.

## What's new since v0.2.0

- **Native desktop app.** A GPUI app replaces the web UI: Kanban board, Current / All-time Sankey funnel, two-layer company and interview briefs, CV tracks and cover-letter toggles, and native macOS notifications. **Try with sample data** opens a fictional workspace with no setup.
- **Chat with any agent.** Hermes, Claude Code, Codex, Pi, OpenCode and custom agents are detected, with their model lists.
- **Run it on a server.** `jh serve` exposes a ledger to the desktop app. On Linux, `jh service install --port N` sets up systemd user units for the server and a 15-minute `jh sync` (commit and push the ledger to git). `jh open --ssh user@host` opens the app on it through an SSH tunnel, and the title shows `ledger · user@host`. See [docs/LINUX-SERVER.md](https://github.com/machineyearningengineer/job-harness/blob/main/docs/LINUX-SERVER.md).
- **Safety rules enforced in code.** Submitting or archiving is refused unless the matching permission is on. Excluded hosts, avoided employers and second applications to the same role through another URL are blocked. Every packet freezes the job ad.
- **Faster, sturdier ledger.** SQLite WAL storage with indexed reads, daily per-channel caps, review urgency tiers, and interview times ranked against your scheduling windows.
- **One-time secret handoff.** `jh secret` passes a login or token through a one-use, owner-only file that is shredded after reading.
- **Easier installs.** One-line installers for macOS, Linux and Windows, a Homebrew formula and cask, and `docs/AGENT-SETUP.md` for setting up through an agent.

Each component also has a `job-harness-local-…` archive (an optional local-model provider, shipped without models). All files are listed in `SHA256SUMS`.

### Opening the unsigned macOS app

The app is not signed with an Apple Developer ID. The first time you open it, right-click **Job Harness.app** and choose **Open**, or run `xattr -d com.apple.quarantine "/Applications/Job Harness.app"`.
