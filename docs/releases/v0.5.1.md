# Job Harness v0.5.1

Local-first AI job search workbench, job application tracker, and MCP server in Rust.

| Platform | Status | Download |
|---|---|---|

All release archives are verified against `SHA256SUMS`.

### Opening the unsigned macOS Desktop App

Job Harness is free, open-source software distributed without an Apple Developer ID signature. On first launch on macOS:

1. Unzip `Job-Harness-v0.5.1-aarch64-apple-darwin.app.zip` and drag **Job Harness.app** into `/Applications`.
2. Right-click **Job Harness.app** → **Open** (or run once in Terminal: `xattr -d com.apple.quarantine "/Applications/Job Harness.app"`).
3. On first launch, click **Try with sample data** to explore a pre-filled 10-role workspace with CVs, interview briefs, Kanban, and Sankey immediately — no terminal or personal data required.

### CLI Quick Install (1 line)

```sh
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/machineyearningengineer/job-harness/main/scripts/get.sh | sh
```

Or paste into Claude Code, Codex, Hermes, Cursor, or OpenCode:
`Read https://raw.githubusercontent.com/machineyearningengineer/job-harness/main/docs/AGENT-SETUP.md and set up Job Harness for me at ~/Career/workspace.`

Fixes for chat and the SSH connection that could leave a reply stuck on "Thinking…" or the link frozen. Nothing to re-run; `jh service install` and `jh service install-agents` write units with `UMask=0077` the next time they run.

## Highlights

- **Chat no longer hangs.** A turn ends even when its prompt fails or the agent host restarted, a late end from a cancelled turn no longer ends the next one, and a client that falls behind is reconnected instead of left waiting.
- **Sessions survive an agent restart.** After an idle agent is stopped (30 minutes) or crashes, the host reopens the session the next message uses, without replaying its history into the chat.
- **The SSH connection cannot freeze.** The supervised `ssh` master no longer writes into a pipe nobody reads, and every control command has a time limit.
- **Private sockets and folders from the start.** Sockets are never open wider than their final mode, and the app's tunnel folder is created 0700 in one step; `get.sh` replaces the binary atomically.
