### Opening the unsigned macOS Desktop App

Job Harness is free, open-source software distributed without an Apple Developer ID signature. On first launch on macOS:

1. Unzip `Job-Harness-v0.4.3-aarch64-apple-darwin.app.zip` and drag **Job Harness.app** into `/Applications`.
2. Right-click **Job Harness.app** → **Open** (or run once in Terminal: `xattr -d com.apple.quarantine "/Applications/Job Harness.app"`).
3. On first launch, click **Try with sample data** to explore a pre-filled 10-role workspace with CVs, interview briefs, Kanban, and Sankey immediately — no terminal or personal data required.

A patch release with the fixes from an outside audit of 0.4.1.

## Highlights

- **`jh sync` never commits a stale `harness.sqlite`.** It holds the exclusive lock from the checkpoint through the commit, fails with `checkpoint_incomplete` if a reader stops the WAL folding in, and pushes after releasing the lock.
- **A newer ledger is left untouched.** The version check reads the schema on a read-only connection before changing anything.
- **`channel` is now required** by `prepare_application` and `prepare_packet` (`portal`, `direct_email` or `recruiter_outreach`). An email is never counted as a portal submission. Prepare older reservations again.
- **Filters match real entries:** `exclude_ats` host suffixes such as `myworkdayjobs.com`, `avoid_list` names with `Ltd` or `Inc.`, salaries with no figure refused, empty location and arrangement lists treated as unset, and duplicate roles across `—`, `:` and `|` title separators.
- **The workspace pin applies to every command**, and an explicit pin file that does not exist refuses.
- **`disabled_cv_tracks` no longer breaks workspace export.**
- **Installers use the `/releases/latest` redirect,** so they are not rate-limited and never pick a prerelease.
